 Água Segura

Sistema de gestão de saneamento e qualidade da água.

 Objetivo

Projeto desenvolvido como laboratório de aprendizado em Django,
visando criar uma plataforma de apoio à gestão de sistemas de abastecimento
e monitoramento da qualidade da água.

 Tecnologias

- Python
- Django
- SQLite
- HTML
- CSS

 Status

Em desenvolvimento
